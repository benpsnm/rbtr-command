# Monthly Retrospective

> Last Sunday of the month. 60 minutes. Ben alone.  
> Not a planning session. A reckoning.

---

## Pre-Work (Do this before you sit down)

Pull these before the session — not during:

- [ ] Atlas monthly summary (run `/monthly-summary` in command centre)
- [ ] Bank statements for all entities — download, don't just scroll
- [ ] Git commit log for the month (`git log --since="[first of month]" --oneline`)
- [ ] Last month's retrospective output — read it before you start

If you skip the pre-work, the session is worthless. Pre-work is the meeting.
