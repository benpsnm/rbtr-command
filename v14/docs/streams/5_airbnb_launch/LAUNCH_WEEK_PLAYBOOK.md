# Launch Week Playbook — 4 Woodhead Mews
## The 7 Days Before the Listing Goes Live

**Principle:** A listing with no reviews is at a structural disadvantage. The goal of launch week is not just to publish — it's to publish with momentum: good photos, complete copy, platform setups done properly, and your first 5+ guests already in the pipeline before you open to public traffic.

---

## PRE-LAUNCH CHECKLIST (Complete before Day 1)

Before the week begins, these must be done:
- [ ] Attic conversion: confirm which areas are photoshoot-ready with contractor
- [ ] Hot tub: service and water test completed
- [ ] Sauna: confirmed operational
- [ ] Ice bath: filled and ready
- [ ] Fire pit: area cleared, logs and firelighters in place
- [ ] All bedrooms: dressed and ready (new or laundered linen on beds)
- [ ] Kitchen: stocked with shoot props (coffee, food items, cutting board)
- [ ] House thoroughly cleaned — not turn-clean, deep-clean
- [ ] Smart lock: code system tested and working
- [ ] WiFi: tested on multiple devices, password confirmed, router position checked
- [ ] Outdoor kitchen: cleaned and functional
- [ ] All three listing copy variants (A/B/C): finalised and ready to paste in

## DAY 4 (Thursday): DIRECT BOOKING SETUP + CHANNEL MANAGEMENT

### Morning: Direct booking page (09:00–12:00)
**09:00** — Decide: does Sarah want a direct booking website at launch?

**Option A — Simple (recommended for launch):** A single landing page (Squarespace or similar, £10/month) with:
- Hero image (Shot 27 — hot tub at dusk)
- Property description (Variant A long copy)
- Price overview
- "Book via Airbnb" button (direct link to listing)
- Sarah's direct email for enquiries

**Option B — Full direct booking:** Integrate a booking engine (Lodgify, Hostaway, Guesty, or Supercontrol) that allows guests to book without going through Airbnb. Charges no platform fee (~3% processing instead of Airbnb's 14%). More work to set up; more valuable at scale.

**Recommendation for launch:** Option A now, Option B within 60 days once listing is established and has reviews.

### Afternoon: Calendar sync and channel management (12:00–16:00)
**12:00** — If using multiple platforms, prevent double-bookings by linking calendars:
- Airbnb: Settings → Calendar → Availability → Export calendar URL (iCal)
- Booking.com: Extranet → Calendar → iCal export
- VRBO: Calendar → Sync

**13:00** — If managing 3+ platforms long-term, consider a channel manager:
- **Hostaway / Guesty / Smoobu** — all sync calendars, messages, and pricing across platforms
- Monthly cost: £50–100/month — worth it if volume justifies
- Not essential at launch; set manual reminders to cross-check calendars daily for first 30 days

**15:00** — Test the full guest journey:
- Find the Airbnb listing as a guest (search "hot tub Barnsley")
- Does it appear? Is the cover photo the hot tub dusk shot?
- Tap through every photo in order
- Read the description — any typos?
- Check the house rules display correctly
- Check the pricing shows correctly for a test date

## DAY 5 (Friday): TEST BOOKING + SOFT LAUNCH TO 10 FRIENDS

### Morning: Internal test booking (09:00–11:00)
**09:00** — Ask a trusted friend or family member to make a test booking (real booking, real money — or use Airbnb's test mode if available, though most hosts just do a real booking they cancel within the free window).

Alternatively: Sarah stays one night herself and goes through the full guest experience:
- Arrive with no knowledge of where anything is
- Find the door code (as if for the first time)
- Turn on the sauna — does the instruction work?
- Use the hot tub — is the cover easy? Water good?
- Cook something in the kitchen — is everything actually there?
- Write down every friction point

**10:00** — Fix every friction point identified. Update the check-in instructions if anything was confusing.

### Afternoon: Soft launch (11:00–17:00)
**11:00** — Publish Airbnb listing (not Booking.com or VRBO yet — Airbnb first)

## POST-LAUNCH: FIRST 30 DAYS

| Week | Focus |
|---|---|
| Week 1 | Respond to every inquiry fast. 100% response rate matters. Accept the first 3–4 bookings from trusted contacts. |
| Week 2 | First guests arrive. Send all pre-arrival messages. Be proactive. Ask for a review the moment they check out. |
| Week 3 | First reviews start landing. Use them: screenshot the hot tub and wellness mentions and post on social. |
| Week 4 | Review pricing — are weekends selling? Are weekdays empty? Adjust accordingly. Activate last-minute discounts if dates unsold inside 7 days. |
| Day 30 | Full review: platform analytics, revenue vs. target, occupancy rate. Decide if Booking.com volume justifies a channel manager. |
